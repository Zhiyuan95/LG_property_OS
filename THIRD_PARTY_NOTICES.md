# Third-party assets

- UI layout, colour palette, map SVG and embedded font resources were adapted from the user-provided `Property Investment OS – 1 · Overview.html` solely as the requested design reference.
- Font families: IBM Plex Sans, IBM Plex Mono and Instrument Serif. These are upstream open-source font families distributed under the SIL Open Font License. Refer to their upstream distributions for copyright notices and license text if redistributing the assets beyond this project.
- Lucide React icons are provided through the `lucide-react` npm dependency under the ISC license.
- React, Next.js and other dependency license texts remain in their installed npm packages. `pnpm-lock.yaml` records the exact dependency tree.
- No third-party listing feed, commercial property imagery, map tile service or external font request is used at runtime.
